## 结论

当前结果差，**主因不是训练轮数不够**。检查并复现出训练增强的图像与标签变换不一致：图像围绕左上角缩放，框却围绕图像中心缩放。随机缩放几乎每批都会启用，所以大部分解冻阶段使用了错误位置监督。把训练延长到 135 轮只会继续拟合一部分错误标签；这次 checkpoint 不应继续训练或用于最终结果。

已修复图像仿射逆矩阵，使 PIL 图像变换和框变换都执行“绕图像中心缩放，再平移”，并增加了确定性测试。此次修复尚未通过新训练验证，因此报告不声称精度已改善。

## 已确认的问题与判断边界

### 已确认：几何增强破坏图像/标签对应关系

对 100×100 合成图执行缩放因子 2、无平移时，框中心从 `(30,30)` 应变为 `(10,10)`。旧 PIL 逆矩阵实际把图像目标移到约 `(60,60)`，而标签仍移到 `(10,10)`。新回归测试检查变换后的亮色目标中心与标签中心，并已通过。

### 次要问题：数据较少、类别分布偏斜、训练学习率恒定

本次只训练 2,501 张 VOC2007 train 图像；对包含 20 类且检测头很大的模型来说，数据相对有限。学习率在 114 轮内恒定，AP 在后段振荡。它们可能限制最终指标，但由于训练同时受增强错位污染，目前无法把 AP 平台归因于某一个次要因素。参考 ResNet-50 迁移实现也使用冻结 backbone、Adam 和 135 轮，但它不能证明本项目的解冻配方或当前结果正确；不同数据处理和评估协议也不可直接比数值。[参考模型](https://raw.githubusercontent.com/tanjeffreyz/yolo-v1/main/models.py)、[参考训练脚本](https://raw.githubusercontent.com/tanjeffreyz/yolo-v1/main/train.py)

### 待单独核查：每图检测数触顶

每图最多 100 个预测是当前评估/后处理配置。绝大多数图片达到该上限时，整体截断可能让低分真阳性消失。修复训练后应同时记录截断前候选数、截断比例、每类分数分布，并比较不设 100 框上限时的 VOC AP；不要单靠调低 confidence threshold 来掩盖排序问题。

## 后续训练策略

1. **不从本次 `best.pt` 或 `last.pt` 恢复。** 二者都在错位增强下训练；从这两份权重续训会保留被污染的模型状态。重新从显式指定的 ImageNet ResNet-50 权重初始化。
2. **先做数据和小样本门槛检查。** 可视化固定图片在多组固定 scale/shift 下的增强图和框；用 16–32 张样本先关闭增强做过拟合检查，再打开修复后的增强。只有小样本能明显拟合，才继续短程 VOC 训练。
3. **短程验证只改一个主要变量。** 保持模型、损失、split、微调阶段和优化器设置不变，先以修复后的几何增强跑 10–15 轮；观察 val AP、每图候选截断率和逐类 AP。确认增强修复后再比较学习率衰减或更大的 VOC07+12 训练集，避免一次改很多项而无法归因。
4. **完整训练前固定数据计划。** 若加入 VOC2012，应固定 train/val 划分并保证 VOC2007 test 完全不参与选配方和选 checkpoint；最终只对选定模型评估一次 test。若暂时只用 VOC2007，明确报告这只是较小训练集实验。
5. **完整 run 恢复十轮保存节奏并保留曲线。** 已停止 run 的部分曲线和两个 checkpoint 已复制到下方目录，供审计；它们不是可用模型。

# FCOS ResNet-50：VOC 训练与测试报告

## 结果

| 数据集划分 | 选择 | 图像数 | mAP@0.5 | mAP@0.5:0.95 |
| --- | --- | ---: | ---: | ---: |
| VOC 2007 val | epoch 85，验证集最佳 | 2,510 | **0.7747** | **0.5023** |
| VOC 2007 val | epoch 120，最后一轮 | 2,510 | 0.7740 | 0.5013 |
| VOC 2007 test | epoch 85 `best.pt` | 4,952 | **0.7777** | **0.5001** |

最终 test 评估使用按验证集 mAP@0.5:0.95 选出的 epoch 85 checkpoint。测试集有 12,032 个标注框；评估最多保留每图 100 个检测，共统计 495,200 个检测候选。逐类 AP 保存在 `test_metrics_best.json`。

测试集逐类 AP@0.5:0.95 较高的类别包括 bus `0.6676`、cat `0.6939`、car `0.6228`；较低的类别为 pottedplant `0.2384`、chair `0.2687`、bottle `0.3066`。数据中 person 占训练框约 32%，测试框约 38%；测试框面积的第 10 百分位约为图像面积的 1.08%，小目标和类别不均衡都值得在后续对照中单独分析，当前结果不能把低 AP 归因于单一因素。

## 实验设置

- 数据：VOC 2007 train + VOC 2012 trainval，共 14,041 张图、33,751 个框；VOC 2007 val 选权重，VOC 2007 test 做最终评估。20 类映射与数据统计见运行目录中的 `dataset_config.yaml` 和 `dataset_analysis.json`。
- 模型：项目 FCOS 实现、ResNet-50/FPN、P3–P7、416×416 输入；图像固定拉伸为正方形。模型预测类别、LTRB 与 centerness。
- 训练：记录完整覆盖 epoch 1–120，micro batch 8、梯度累积 2、有效 batch 16、BF16、SGD，检测头初始 LR 0.005、backbone LR 倍率 0.1；前 3 epoch 冻结 ResNet，epoch 80 和 105 将学习率各衰减 10 倍；每 10 epoch 保存 checkpoint、每 5 epoch 验证。训练 loss 从 epoch 1 的 `1.3553` 降到 epoch 120 的 `0.6926`。
- 设备环境：NVIDIA GeForce RTX 4060 Ti 16 GB，Python 3.10.12、PyTorch 2.10.0+cu128、TorchVision 0.25.0+cu128、CUDA 12.8。
- 训练代码 revision：`9ed5a7cef00f864768ee442313850dd4be414410`。
- 参考来源和论文差异：本实现自行实现 FCOS 分配、head、loss 与 decoder，参考 MMDetection 3.3.0 FCOS 配置；采用 ImageNet RGB 归一化、项目增强与 VOC 训练日程，不是 MMDetection COCO recipe 的逐项复现。运行配置记录从本地 `best.pt` 恢复训练，但没有记录该初始 checkpoint 的来源路径/hash；TorchVision ResNet-50 ImageNet1K_V1 文件在本机缓存中，但不能仅凭本次 run metadata 证明恢复点的完整来源链。

## 曲线与验证观察

epoch 80 学习率衰减后，验证 AP 持续提升，epoch 85 达到最佳 mAP@0.5:0.95 `0.5023`。epoch 90–120 的验证 mAP@0.5:0.95 在 `0.5008–0.5020` 间小幅波动，未超过 epoch 85；训练 loss 仍缓慢下降，说明后段训练收益已经趋缓，继续按当前配置训练没有刷新最佳验证 checkpoint。

验证 mAP@0.5 从 epoch 1 的 `0.6517` 上升到 epoch 85 的 `0.7747`，最后一轮为 `0.7740`。epoch 105 学习率再次衰减后，验证指标仍接近平台，没有明显恢复到新的最佳点。后续若继续优化，应固定数据和其余配方，单独检查定位损失/目标尺度处理或小目标增强；这次结果不足以支持同时改多个训练因素。

## 同一 VOC 2007 test 划分上的项目参考

| 模型/变体 | mAP@0.5 | mAP@0.5:0.95 |
| --- | ---: | ---: |
| YOLOv1 ConvNeXt-Small 工程版 | 0.6875 | 0.3185 |
| YOLOv2 项目实现 | 0.6936 | 0.3941 |
| YOLOv3-head + ConvNeXt-Small | 0.7937 | 0.4454 |
| FCOS ResNet-50 | 0.7777 | 0.5001 |
| RTMDet-Tiny | 0.8171 | 0.6005 |

FCOS 的 AP@0.5:0.95 高于项目 YOLOv1/v2/v3 结果，说明较严格 IoU 下的整体框质量比这些既有 run 好；AP@0.5 仍低于 YOLOv3 和 RTMDet-Tiny，且整体低于 RTMDet-Tiny。各实验的骨干、预训练权重、训练日程和增强不同，不能把差距只归因于检测头或论文版本。VOC test 已用于项目历史比较，因此以上是统一数据划分的项目内参照，不是外部盲测结论。

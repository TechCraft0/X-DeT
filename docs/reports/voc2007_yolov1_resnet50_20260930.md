日期：2026-09-30

- 转换器默认移除 `difficult=1`：train/val/test 分别移除 1,543 / 1,511 / 2,944 个目标。完整统计见数据目录中的 `conversion_report.json`。

## 实现与训练设置

本次使用项目内的 `yolov1_resnet50_transfer` 教学变体：冻结 ImageNet 预训练 ResNet-50 backbone，并训练 YOLOv1 风格检测头；输入 448×448，7×7 网格，每格 2 个框，20 类。它不是 YOLOv1 论文中的 Darknet 网络，也不应称为严格复现。参考代码：[yakhyo/yolov1-pytorch](https://github.com/yakhyo/yolov1-pytorch)、[tanjeffreyz/yolo-v1](https://github.com/tanjeffreyz/yolo-v1)。

| 项目 | 设置 |
|---|---|
| 训练轮数 | 135（先做 30 轮诊断，再从 checkpoint 恢复继续到 135） |
| 训练步数 | 84,375 个 batch step；每轮 625 step |
| 批大小 | micro batch 4，梯度累积 16 步，有效 batch 64 |
| 优化器 | SGD，momentum 0.9，weight decay 0.0005 |
| 学习率 | 1e-4，首轮从 1e-5 warmup；完整阶段在第 75、105 轮各衰减 10 倍 |
| loss | λcoord=5，λnoobj=0.5 |
| 随机种子 | 42 |
| 评估后处理 | confidence 0.001，NMS IoU 0.45，每图最多 100 个检测 |
| 环境 | Python 3.10.12，PyTorch 2.10.0+cu128，CUDA 12.8，NVIDIA GeForce RTX 4060 Ti |
| 训练用时 | 约 4 小时 38 分钟，从第一阶段 run 配置创建到第 135 轮 checkpoint 写入；不含后续 test 评估 |

第一阶段使用 30 轮诊断配方；恢复其模型与优化器 checkpoint 后，第二阶段采用完整 135 轮配方的学习率计划。完整阶段从第 31 轮重新以 1e-4 学习率继续，checkpoint 的 global step 连续累计。首阶段和完整阶段的配置快照都保存在 run 目录中。

训练从第 1 轮 total loss 18.18 降到第 135 轮 4.38；验证 mAP 随训练整体提升，但后期逐渐平台化。最佳 checkpoint 按验证 mAP@[0.50:0.95] 选出，为第 135 轮。
